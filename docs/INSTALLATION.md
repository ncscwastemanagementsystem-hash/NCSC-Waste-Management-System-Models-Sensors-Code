# Installation and Usage

## Python environment
Python 3.10 or 3.11 is recommended.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

## Train the example sensor-fusion model
```bash
python ai_models/random_forest/train_fusion_model.py --csv sample_data/synthetic_sensor_dataset.csv
```
This demonstrates that the pipeline executes. The CSV is synthetic; its metrics are not real-world performance evidence. Replace it with a representative labelled dataset and independent test split.

## Run a single prediction
```bash
python ai_models/random_forest/predict_fusion.py --visual-class plastic --visual-confidence 0.91 --metal-detected 0 --weight-g 18 --moisture-pct 4 --capacitive-raw 220
```
Requires a model generated by the training script.

## YOLO camera inference
```bash
pip install -r requirements-yolo.txt
python ai_models/yolo/detect_camera.py --weights /path/to/your/best.pt --source 0
```
Custom trained waste weights are not included. A generic pretrained model may not have the project's required classes.

## ESP32
Install Arduino IDE, the ESP32 board package, ESP32Servo library and HX711 library as required by the selected sketch. Select the correct board and port. Review pin assignments and electrical interfaces before wiring. Higher-voltage sensor outputs require suitable level shifting/isolation.

## Serial telemetry
```bash
python software/serial_bridge.py --port COM4
# Linux example: --port /dev/ttyUSB0
```

## Tests
```bash
pytest -q
```
